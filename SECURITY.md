# Security Policy

## Supported Versions

AKS Framework is currently under active development. Security fixes will be prioritized for the latest release.

| Version | Supported |
| --- | --- |
| 0.1.x | :white_check_mark: |
| < 0.1.0 | :x: |

Support for future versions will be updated as the project matures.

## Reporting a Vulnerability

If you discover a potential security vulnerability in AKS Framework, please report it responsibly.

**Please do not disclose unpatched vulnerabilities in public GitHub issues.**

To report a vulnerability, use GitHub's private vulnerability reporting feature if it is enabled for this repository:

https://github.com/aksinghsoftwaresolution/aks-framework/security/advisories/new

Please include the following information in your report:

- A description of the vulnerability and its potential impact.
- The affected version and relevant files or components.
- Steps to reproduce the issue or a proof of concept.
- Any suggested mitigation, if available.

### What to Expect

The maintainers will review the report, may request additional information, and will work to assess the severity and determine an appropriate fix.

Please allow reasonable time for investigation and remediation before publicly disclosing the vulnerability.

Security updates and release information will be published when applicable.
